主题：创建一个 Bakery 数据库，字段 productName 和 productDay; 用 generator code 创建 API、测试并提交。

← 返回 Quiz 2 复习总览

操作流程说明（考试时按这个顺序做）

  1. 建数据库：Atlas 或本地 MongoDB 都可以，关键是拿到 URI。Atlas URI 里数据库名建议写 bakery。
  2. 放 URI：新建 .env，写 MONGODB_URI=你的连接串; 确认 .gitignore 忽略 .env。
  3. 写 generator code：第一行 require('dotenv').config(); 然后 express / mongoose / express.json()。
  4. 写 Schema / Model：字段 productName、productDay，都是 String + required + trim; Model 名叫 Product，集合默认 products。
  5. 定义 REST URL：GET /api/products、POST /api/products、GET /api/products/:id、PUT /api/products/:id、DELETE /api/products/:id。
  6. 连接并启动：先 await mongoose.connect(process.env.MONGODB_URI)，成功后再 app.listen(...)。
  7. 测试：Postman/curl 测 GET/POST/PUT/DELETE; 看状态码 200/201/204/400/404; 再去 mongosh 或 Atlas Browse Collections 确认数据真的写入。
  8. 提交：只提交代码与说明，不提交真实 .env 或密码文件。
安全提醒：URI 含密码，只能放 .env 或部署平台的 Environment Variables，不能写进 server.js 或提交到 GitHub。

Generator code 骨架（你必须看懂每一部分）

require('dotenv').config({ quiet: true });
const express = require('express');
const mongoose = require('mongoose');

const app = express();
app.use(express.json());

const productSchema = new mongoose.Schema({
  productName: { type: String, required: true, trim: true },
  productDay:  { type: String, required: true, trim: true }
}, { timestamps: true });

const Product = mongoose.model('Product', productSchema);

app.get('/api/products', async (req, res) => {
  res.json(await Product.find());
});

app.post('/api/products', async (req, res) => {
  const { productName, productDay } = req.body;
  const doc = await Product.create({ productName, productDay });
  res.status(201).json(doc);
});

app.get('/api/products/:id', async (req, res) => {
  const doc = await Product.findById(req.params.id);
  if (!doc) return res.status(404).json({ message: 'Not found.' });
  res.json(doc);
});

async function start() {
  await mongoose.connect(process.env.MONGODB_URI);
  app.listen(process.env.PORT || 3000);
}
start();
