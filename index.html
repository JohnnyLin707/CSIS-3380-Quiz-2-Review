4. Bakery 例子：你考试时应该怎么做

4-1 字段设计

productSchema = {
  productName: { type: String, required: true, trim: true },
  productDay:  { type: String, required: true, trim: true }
}
Model: Product
Collection: products
Database URI: .../bakery 或任何老师指定的数据库名

4-2 URL 设计

操作Method + URL说明
读取全部`GET /api/products`集合路径用复数 products
读取单个`GET /api/products/:id``req.params.id` 取路径参数
新增`POST /api/products`成功返回 `201`
更新`PUT /api/products/:id`成功返回 `200` 或 `204`，看生成器模板
删除`DELETE /api/products/:id`成功返回 `204`
查询某天产品`GET /api/products?productDay=Monday``req.query.productDay` 取 query string

4-3 最关键的代码逻辑

require('dotenv').config();

app.use(express.json());

mongoose.connect(process.env.MONGODB_URI);

const Product = mongoose.model('Product', productSchema);

app.post('/api/products', async (req, res) => {
  const doc = await Product.create({
    productName: req.body.productName,
    productDay: req.body.productDay
  });
  res.status(201).json(doc);
});

app.listen(process.env.PORT || 3000);

5. Module 7 为什么不是主线

Module 7 两个文件夹主要是：

  • React Router：`BrowserRouter`、`Routes`、`Route`、`Link`、`NavLink`、`useParams`、`useNavigate`。
  • Deployment：Render / Vercel / GitHub Pages，以及 React Router 刷新子路由 404 的问题。
老师这次说的“URL”是后端 REST API URL 定义，即 `/api/products` 这种；不是 React Router 的前端页面 URL。Module 7 只需知道概念区别，不必重点复习。
